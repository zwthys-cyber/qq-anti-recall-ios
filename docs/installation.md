# 安装与使用

## 安装或升级

插件只适配 QQ 9.3.86（9.3.86.617）。从成功的 GitHub Actions 运行下载对应版本产物，检查包内 `build-info.json` 和 `SHA256SUMS`。

将 `QQAntiRecall.dylib` 注入匹配的已解密 QQ IPA，使用你已有的工具与宿主一并重签名安装。升级时替换旧动态库，不要叠加注入。构建产物的 ad-hoc 签名不是可直接安装到手机的签名。

重签名安装是否保留原沙盒数据，取决于你的签名与安装流程；不要把覆盖安装视为数据备份。仓库不提供 QQ 安装包或签名材料。

## 设置入口

进入 **QQ 设置 → QQ 增强 · 插件设置**。设置页使用原生分组列表，支持系统字体大小和深色模式。聊天页面没有常驻悬浮按钮。

### 消息防撤回

开启后保存已接收到的消息模型。收到撤回后，保留的消息下方显示标识；重新进入聊天时尝试用本机快照恢复。

未被插件保存过的消息不能追溯恢复。普通媒体只保存模型与路径，不额外保全视频、文件等附件本体。

### 闪照保留

独立开关，默认关闭。先开启，再正常打开一张新闪照。在对应消息下方点击“闪照 · 再次查看”可重复打开副本。

回看入口就在聊天中，设置页不提供闪照相册。关闭会隐藏回看入口并停止新增；清理闪照才会删除副本。

### 自定义机型

1. 在插件设置打开“自定义机型”，填写希望显示的机型并保存到插件。
2. 进入 QQ 官方的“自定义设备名”页面，等待页面加载后点击官方保存按钮。
3. 收到服务端接受提示后，让好友确认显示。

插件同步修改已识别请求的机型与显示机型字段，保留官方“自定义文字”前缀。不会用本机预览冒充好友端验证，也不修改系统全局机型。

0.7.1 已有目标用户确认好友可见；不保证所有输入或账号均被服务端接受。关闭覆盖只停止后续修改。恢复默认时，先关闭插件覆盖，再使用 QQ 官方页面恢复默认并保存。

### 通话录制免提醒

独立开关，默认关闭。在开始录制前开启“通话录制免提醒”（0.9.2 起同时静音本机录制结束提示音），插件会拦截一对一语音／视频通话中发给对方的开始、结束及重发的录制状态通知。

仅屏蔽本机开始／结束状态（1、3、8）。保留中止对方录制的指令、确认消息、本机录制入口及收到的对方录制通知。关闭开关后，后续通知按 QQ 原逻辑发送；已经发送的提醒无法撤回。不覆盖群通话、系统录制提示或其他应用。

本版已核对 QQ 9.3.86.617 的静态接口，尚未完成真实 QQ 双端验证。升级后分别检查语音与视频通话的开始、结束录制、文件保存和对方是否收到提醒。若录制异常，关闭该开关并导出诊断。

### 清理与诊断

清理仅针对当前账号的插件副本，确认后执行。重置诊断计数不清理内容。导出诊断生成 JSON 文件，可通过系统分享面板发送；排查 UI 卡顿时同时说明是滑动、收到消息还是打开闪照时出现。
